deidentify

Detect, redact and pseudonymize the HIPAA Safe Harbor identifiers in a clinical note, entirely in your browser. The rules run instantly; the optional NER layer downloads a small model once and runs it on WebGPU when the browser has it, otherwise in WebAssembly. Nothing leaves this page. GitHub · npm
